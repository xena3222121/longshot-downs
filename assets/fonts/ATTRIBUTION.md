# Font Attribution

## PlayfairDisplay-Variable.ttf

- **Font:** Playfair Display (variable font, weight axis 400–900)
- **Author:** Claus Eggers Sørensen
- **Source:** https://github.com/google/fonts/tree/main/ofl/playfairdisplay (Google Fonts mirror)
- **License:** SIL Open Font License 1.1 (see `OFL-PlayfairDisplay.txt`) — free for commercial use,
  no attribution legally required, but credited here for completeness.
- **Usage in this game:** the one type family used everywhere — heavier weights (SemiBold/Bold/Black)
  for titles and headers, lighter weights (Regular/Medium) for buttons and body text — via Godot's
  `FontVariation` resource setting the `wght` OpenType axis, rather than mixing multiple font files.
